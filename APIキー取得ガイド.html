AIのAPIキー取得ガイド

「特定健診ノート（健康ノート）」でAIに相談するための準備

2026年11月11日時点の情報です。各社の画面や料金は変わることがあります。画面の表示が違うときは、同じ意味のボタンを探してください。

1. APIキーとは

APIキーは、アプリがあなたの代わりにAIへ問い合わせるための「合い鍵」です。長い英数字の文字列で、AIの会社のサイトで発行します。発行したキーをアプリの「⚙ 設定」画面に1回貼り付ければ、あとはアプリからAIに相談できます。パソコンとスマホの両方で使う場合は、同じキーをそれぞれに貼り付けます。

3社すべてのキーを取る必要はありません。どれか1つあればアプリは使えます。

2. どのAIを選ぶか

AI必要なもの費用こんな方に
Gemini（Google）Googleアカウント無料枠あり（カード登録なしで始められる）まず試したい方。最初の1つとしておすすめ
Claude（Anthropic）メールアドレス、クレジットカード前払い制（5ドルから）。使った分だけ残高から引かれるGoogleアカウントがない方、回答を読み比べたい方
ChatGPT（OpenAI）メールアドレス、クレジットカード前払い制（5ドルから）。使った分だけ残高から引かれる同上
ChatGPTやClaudeの月額プランとは別のものです。チャット画面の有料プラン（月額制）に入っていても、APIキーの利用料は含まれません。APIは開発者向けの別サイトで、別に支払います。

費用の目安

健診データや毎日の記録の相談は文章量が少ないため、1回（医師4人分）で数円から数十円程度です。前払いの5ドルで、年に数回の相談なら長く使えます。正確な料金は各社の料金ページで確認してください。

健診データの扱いについて

Geminiの無料枠では、送った内容がGoogleのサービス改善に使われることがあります。気になる方は、有料の設定に切り替えるか、ClaudeまたはChatGPTを選んでください。アプリは相談のとき氏名を送りませんが、健診票や薬の写真を読み取るときは、写真に印字された氏名なども送られます。

3. Gemini（Google）のキーを取る

所要時間：約5分。用意するもの：Googleアカウント（Gmailのアドレス）。

  1. ブラウザで https://aistudio.google.com/apikey を開きます。
  2. Googleアカウントでログインします。初回は利用規約の同意画面が出るので、内容を確認して同意します。
  3. Create API key（APIキーを作成）を押します。
  4. プロジェクトを選ぶ画面が出たら、そのまま新しいプロジェクトで作成します（名前は初期値のままで構いません）。
  5. キー（長い英数字）が表示されます。Copy（コピー）を押します。
  6. 特定健診ノート（開くと「健康ノート」と表示されます）を開き、右上の「⚙ 設定」→「AIのキー」の Gemini の欄にキーを貼り付けて、保存して確かめる を押します。「使えます」と出れば完了です。
無料枠には1分あたり・1日あたりの回数制限があります。「429」や「上限に達しました」と出たら、少し待ってからもう一度試してください。

4. Claude（Anthropic）のキーを取る

所要時間：約10分。用意するもの：メールアドレス、クレジットカード。

  1. ブラウザで https://platform.claude.com を開きます（以前の console.anthropic.com からも同じ場所に移動します）。
  2. メールアドレスまたはGoogleアカウントで登録します。メールに届く確認の案内に従います。
  3. 氏名などの質問に答えます。利用目的を聞かれたら「個人（Individual）」で構いません。
  4. Billing（請求）を開き、クレジットカードを登録して利用分（クレジット）を購入します。最低額は5ドルです。
  5. API keys を開き、Create key を押します。名前は「健診ノート」など分かるものにします。
  6. キー（sk-ant- で始まる文字列）が表示されます。この画面でしか表示されないので、すぐにコピーします。
  7. 特定健診ノート（開くと「健康ノート」と表示されます）を開き、右上の「⚙ 設定」→「AIのキー」の Claude の欄にキーを貼り付けて、保存して確かめる を押します。「使えます」と出れば完了です。
使いすぎが心配な方は、Limits で月ごとの上限額（Spend limit）を設定できます。自動で追加購入する設定（Auto reload）はオフのままにしておくと、残高以上は使われません。

5. ChatGPT（OpenAI）のキーを取る

所要時間：約10分。用意するもの：メールアドレス、クレジットカード、携帯電話（確認コードの受信用）。

  1. ブラウザで https://platform.openai.com を開きます。ChatGPTのチャット画面（chatgpt.com）とは別のサイトです。
  2. 登録またはログインします。ChatGPTと同じアカウントが使えます。
  3. 右上の歯車（Settings）から Billing（請求）を開き、クレジットカードを登録して利用分を購入します。最低額は5ドルです。
  4. API keys を開き、Create new secret key を押します。名前を付けて作成します。
  5. キー（sk- で始まる文字列）が表示されます。この画面でしか表示されないので、すぐにコピーします。
  6. 特定健診ノート（開くと「健康ノート」と表示されます）を開き、右上の「⚙ 設定」→「AIのキー」の ChatGPT の欄にキーを貼り付けて、保存して確かめる を押します。「使えます」と出れば完了です。
自動で追加購入する設定（Auto recharge）はオフのままにしておくと、残高以上は使われません。

6. キーを安全に扱う

  • キーは他人に教えない。メール、LINE、SNS、写真で送らないでください。知られると、あなたの料金で使われるおそれがあります。
  • キーを控えておく場合は、パスワードと同じ場所（パスワード管理アプリや紙のメモ）に保管します。
  • 家族や他人と共用のパソコン・スマホには入力しないでください。
  • 知られたかもしれないと思ったら、各社のAPIキーの画面でそのキーを削除（Delete / Revoke）し、新しいキーを作り直します。
  • パソコンやスマホを手放すときは、アプリの「⚙ 設定」→「すべて消す」でキーを消してください。

7. うまくいかないとき

症状確認すること
キーを貼ったのに「キーが正しくありません」（401）コピーのときに前後の空白や文字の欠けがないか。別のAIの欄に貼っていないか
「残高がありません」「クレジット不足」（Claude / ChatGPT）キーの作成だけでは使えません。Billing で利用分を購入したか確認します
「回数の上限です」（429）少し待ってからやり直します。Geminiの無料枠では起こりやすくなります
キーをコピーし忘れて画面を閉じた同じキーはもう表示できません。新しいキーを作り直します（古いキーは削除）
「Create API key」が押せない（Gemini）会社や学校のGoogleアカウントでは制限されることがあります。個人のGoogleアカウントで試します
ChatGPTの有料プランに入っているのに使えないAPIは別払いです。platform.openai.com の Billing で購入が必要です
