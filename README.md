# 健康ノート（HelthChk_Yearly_v3）

Care your health yourself. This app support you and make yourself healthy.

健康管理アプリ、毎年行う特定健診データと毎日の気づきがあなたの健康を守ります。気になるところはAIドクターに問い合わせることができます。日々の細かな不安を解消しましょう。

毎年の特定健診の結果と、日々の体調の気づきを記録するアプリです。パソコンでもスマホでも、インターネットを見る画面（ブラウザ）で開いて使います。特別なソフトを入れる必要はありません。

## このアプリでできること

- **特定健診の結果を保存** — 最大10年分を並べて、数値の変化が見られます。各項目に「基準値」と「国際的な目安」も表示されます
- **健診票の写真をAIに読み取ってもらう** — 紙の健診票を写真に撮るだけで、数値を取り込めます（手で入力もできます）
- **家族の分も記録** — 複数人の記録を切り替えて管理できます
- **毎日の記録** — 血圧・体重・血糖・歩数などを残せます。「1週間のまとめ」も見られます
- **AIドクターに相談** — かかっている病気、飲んでいる薬、心配なことを踏まえて、AIに質問できます。薬の写真から、飲んでいる薬を読み取ることもできます
- **グラフと印刷** — 変化をグラフで見たり、結果を印刷したりできます
- **文字の大きさを変更** — 見やすい大きさに変えられます

## はじめ方

開き方は2通りあります。どちらでも同じアプリが始まります。

**方法1: アドレスで開く**
配布されたアドレス（URL）をブラウザで開くだけです。スマホでもパソコンでも使えます。

**方法2: ファイルで開く**
`index.html` をダブルクリックすると、ブラウザでアプリが開きます。

**スマホでは**、ホーム画面にアイコンを作っておくと、次からアプリのように開けます。

- iPhone: Safariの共有ボタン →「ホーム画面に追加」
- Android: Chromeの「︙」→「ホーム画面に追加」

## AIドクターを使うには（APIキー）

AIに読み取りや相談をしてもらうには、「APIキー」と呼ばれる合言葉のようなものが必要です。

- アプリの「設定」画面で、自分のAPIキーを入れます（Claude / Gemini / OpenAI から選べます）
- 取り方は、**`APIキー取得ガイド.html`** に分かりやすく書いてあります。無料で始められる方法もあります
- APIキーは、端末ごとに1回入れるだけです。他人に教えないでください

APIキーを入れなくても、記録・表示・グラフ・印刷はそのまま使えます。

## データについて（大事なこと）

- 入力した内容は、**あなたの端末（パソコンやスマホ）のブラウザの中**に保存されます。インターネット上の置き場には送られません
- **アドレスで開いた場合と、ファイルで開いた場合では、保存場所が別々**になります。いつも同じ開き方をしてください
- ブラウザの「履歴やデータを消す」操作をすると、保存した内容も消えてしまうことがあります
- **控えの保存**: 「設定」から、データの控えをファイルに保存できます。万一に備えて、時々保存しておくと安心です
- パソコンとスマホで同じデータを使いたい場合は、「設定」から Google スプレッドシートへの保存も選べます

## 大事な注意

- AIドクターの答えは、**お医者さんの診断ではありません**
- 検査の数値が心配なときや、つらい症状があるときは、必ず病院で相談してください
